# TechMind AI Academy v0.2.0

## Destaques

A versão **v0.2.0** consolida o primeiro MVP full stack da TechMind AI Academy com autenticação, trilhas, matrículas e progresso persistido.

## Funcionalidades

- cadastro e login de alunos
- autenticação stateless com JWT HS256
- senhas protegidas com BCrypt
- perfil do usuário autenticado
- catálogo público de trilhas
- matrícula em cursos
- progresso por trilha
- XP acumulado
- progresso agregado
- simulador de entrevista técnica
- migrations Flyway
- PostgreSQL 17
- frontend React + TypeScript + Vite
- Docker Compose
- health check com Actuator

## Engenharia

- Java 21
- Spring Boot 3.5.5
- Spring Security
- Spring Data JPA / Hibernate
- PostgreSQL 17
- Flyway
- React 19.1.1
- TypeScript 5.9.2
- Vite 7.1.7
- Docker / Nginx
- CI com GitHub Actions para backend, frontend e Docker
- documentação arquitetural em Mermaid

## Segurança

- secrets externalizados por variáveis de ambiente
- `.env` fora do versionamento
- validação do issuer JWT
- secret JWT mínimo de 32 bytes
- endpoints privados por padrão
